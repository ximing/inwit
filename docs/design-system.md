# Inwit 设计系统 v1 ——「纸上学习」

> 设计基调：一张温热的纸。你在上面写字，AI 帮你做批注。
> 语言：宣纸（底）、墨色（字）、朱批（强调）、签条（标签/卡片）。
> 这是给 C 端学习者的产品，不是管理后台：克制、安静、有呼吸感。

---

## 1. 设计原则

1. **纸感不是拟物**：不用纸张纹理图片，用色温、留白、柔和投影营造"纸"的感觉
2. **内容即界面**：文档和卡片是主角，chrome（导航/按钮）退后——细线、弱色、小字号
3. **一处大胆**：全产品唯一的高饱和色是「朱批红」，只用于关键动作和批注标记，其余全部低饱和
4. **明暗双主题**：亮色=白日书桌，暗色=灯下夜读（暖黑，不是纯黑、不是冷灰蓝）
5. **动效有因果**：只回应用户动作（展开、翻面、保存），不做页面加载花式入场

## 2. 色彩 Tokens

所有颜色定义为 CSS 变量，`[data-theme="light|dark"]` 切换。禁止在组件里写死 hex。

### 2.1 亮色（白日书桌）

| Token | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#F7F3EC` | 页面底（宣纸，暖米白） |
| `--bg-raised` | `#FDFBF7` | 卡片/编辑器纸面 |
| `--bg-sunken` | `#EFE9DF` | 侧边栏/凹陷区/输入框底 |
| `--bg-overlay` | `#FFFEFA` | 弹层/下拉 |
| `--ink-primary` | `#292524` | 正文（暖墨黑，不用纯黑） |
| `--ink-secondary` | `#6B6259` | 次要文字 |
| `--ink-faint` | `#A39A8D` | 占位/时间戳 |
| `--line` | `#E4DCCC` | 分隔线/边框（纸痕色） |
| `--accent` | `#C2402A` | **朱批红**：主按钮、批注、关键强调 |
| `--accent-ink` | `#FFFFFF` | 朱底上的字 |
| `--accent-soft` | `#F5E0DA` | 朱红的淡底（hover/选中态） |
| `--anchor` | `#F3E3B3` | 文档中卡片锚点高亮（批注黄） |

## 3. 字体

| 角色 | 字体栈 | 说明 |
|---|---|---|
| UI 界面 | `-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` | 导航、按钮、表单 |
| 文档/卡片正文 | `"Songti SC", "STSong", "Noto Serif SC", "SimSun", serif` | **衬线**——长文阅读纸感的关键，卡片正文同用 |

字号阶（rem，base 16）：
```
--text-xs: .75   时间戳/标签
--text-sm: .8125 次要说明/表格
--text-base: .9375 UI 正文（15px，比常规 14 稍松）
--text-md: 1.0625 文档正文（17px 衬线）
--text-lg: 1.25  卡片概念/小节标题
--text-xl: 1.625 页面标题
--text-2xl: 2.125 文档大标题
```
字重：400 正文 / 500 强调 / 600 标题。行高：UI 1.5 / 衬线正文 1.8 / 标题 1.3。
行长：文档正文容器 max-width 680px（约 40 个中文字），居中。

## 4. 圆角 / 间距 / 边框

```
--radius-sm: 6px   标签、小按钮、输入框
--radius-md: 10px  卡片、弹层
--radius-lg: 14px  对话框、编辑器纸面
（不用胶囊形大圆角，不用 0 圆角）
```
间距阶：4 的倍数，`--space-1:4px … --space-6:24px --space-8:32px --space-12:48px`。
边框统一 1px `var(--line)`；不用双层边框。

## 5. 组件规范

### 按钮
- 主按钮：`--accent` 底白字，radius-sm，padding `8px 16px`，font-weight 500，hover 亮度 +6%，active 下沉 1px。全App只有它是高饱和
- 次按钮：透明底 + `--line` 边框 + `--ink-primary` 字
- 幽灵按钮：无边框 `--ink-secondary`，hover 出 `--bg-sunken` 底
- 危险操作：幽灵按钮 + `--bad` 字（不用红底）

### 卡片（知识卡）
- `--bg-raised` 底 + `--shadow-1` + radius-md + 1px `--line`
- 结构：概念（衬线 --text-lg 600）→ 例子（衬线正文，前缀「例子」小字标签）→ 易混点（同结构）→ 标签行
- 标签： `--bg-sunken` 底、`--ink-secondary`、radius-sm、--text-xs、padding `2px 8px`
- hover：shadow-1→shadow-2，不上浮位移

### 复习三档按钮
忘了=`--bad` 描边 / 模糊=`--warn` 描边 / 想起来了=`--ok` 描边；选中时对应淡底填充。语义色只做描边和图标，不做大色块

### 导航（左侧细栏 220px）
- `--bg-sunken` 底，无右边框阴影，只有 1px `--line`
- 项：icon(16px) + 文字（--text-sm），选中态=左侧 2px `--accent` 竖条 + `--accent-soft` 底
- 顶部品牌：「Inwit」衬线 --text-lg + 一句 slogan `--ink-faint` --text-xs

### 快捷捕捉条（首页顶部）
- 单行输入框，`--bg-raised` + `--line`，radius-md，placeholder「扔一句话进来，或以问号结尾问 AI」
- 右侧两个幽灵按钮：「问 AI」「扔进去」，输入非空才高亮主按钮

### 编辑器（tiptap）
- 纸面：`--bg-raised` + radius-lg + `--shadow-1`，padding `48px 56px`，max-width 800px 居中
- 正文衬线 --text-md/1.8；标题自动层级；placeholder `--ink-faint`
- 工具栏：浮动选中条（加粗/标题/列表/引用），不打断写作
- **锚点高亮**：被 AI 切出卡片的段落，背景 `--anchor`，左侧 2px `--anchor-strong` 竖条，hover 微亮，点击右侧滑出对应卡片

### 弹层/对话框
- `--bg-overlay` + radius-lg + `--shadow-3`，无遮罩模糊（遮罩用 `rgba(41,37,36,.28)` 纯色）

### 主题切换
- 设置页 + 侧边栏底部一个 icon 按钮（日/月），`document.documentElement.dataset.theme` 切换，localStorage 持久化，默认跟随系统 prefers-color-scheme

### 焦点与无障碍
- focus-visible：2px `--accent` outline + 2px offset（不用默认蓝框）
- 所有交互元素 ≥32px 点击区；正文对比度 ≥4.5

## 6. 关键页面布局

### 6.1 首页 = 文档列表
```
┌────────┬──────────────────────────────────────────┐
│ 侧栏    │  [快捷捕捉条__________________] [问AI][扔] │
│        │                                          │
│ 文档    │  最近文档                                │
│ 复习    │  ┌ 文档条目 ──────────────────────┐      │
│ 主题    │  │ 过拟合笔记          2卡 · 刚刚  │      │
│        │  │ L1和L2正则化        2卡 · 昨天  │      │
│ 设置    │  └──────────────────────────────┘      │
│ 后台    │  （条目：衬线标题 + 元信息一行，细线分隔，│
│        │   不是卡片堆叠）                         │
└────────┴──────────────────────────────────────────┘
```

### 6.2 文档阅读页（核心形态）
```
┌ 返回 · 文档标题（衬线大标题）          [编辑][…] ┐
│                                                │
│  正文段落…………………………【锚点高亮的段落】▏      │
│  …………………………………………………………       ┌───────┐
│  正文继续………………………………………………        │ 关联卡 │
│                                     ▏高亮激活   │ 片滑出 │
│                                                │ 面板   │
│                                                └───────┘
└────────────────────────────────────────────────┘
```

### 6.3 卡片详情页
- 上半：卡片本体（概念/例子/易混点/自测题）
- 「出处」条：来自《文档标题》→ 点击回文档并滚动到锚点
- 「相关卡片」：横向小卡列表（同概念/易混淆/前置），点击跳转

### 6.4 复习页
- 居中窄栏（560px），抽认卡是大纸面（radius-lg + shadow-2）
- 卡片显示「关联 3 张」小字轻提示（不打断流）
- 三档反馈按钮在底部固定

### 6.5 主题页（知识地图主视图）

主题页是产品的第二核心页面。心智：一张正在生长的讲义大纲。

```
┌ 主题：机器学习基础            [整理地图][归档][…] ┐
│ 目标：一个月掌握核心概念                          │
│ ▓▓▓▓▓░░░░░ 已覆盖 5/9 概念 · 12 张卡 · 掌握 62% │
│ [地图] [资料流]  ← tab                           │
│                                                │
│ ▾ 基础概念                          4卡 · 2资料 │
│   ● 偏差-方差权衡            ●2卡 📄  掌握·绿点 │
│   ● 正则化                  ●2卡      掌握·绿点 │
│ ▾ 训练问题                          5卡 · 3资料 │
│   ◐ 梯度消失                ●3卡 📄2  在学·半满 │
│   ◐ 梯度爆炸                ●1卡      在学·半满 │
│ ▸ 优化器                              0卡      │
│   ○ 学习率调度（虚线=空白节点，点击→「让 AI 补」）│
└────────────────────────────────────────────────┘
```

**节点样式**（三级以内，再深 Agent 自己合并）：
- 章节行（有子节点）：--text-base 500，`▾/▸` 折叠符，右侧元信息（N卡 · M资料）`--ink-faint` --text-xs
- 概念节点：概念名（衬线 --text-base）+ 状态点 + 卡数徽标 + 资料图标
- **状态点**（10px 圆，不用图标字体）：
  - `covered` 掌握：实心 `--ok`（节点平均掌握度 ≥80%）
  - `learning` 在学：半满 `--warn`（有卡但掌握度 <80%）
  - `uncovered` 空白：**虚线描边空心圆 `--ink-faint`**，节点名也用 `--ink-faint`，右侧一个幽灵小按钮「让 AI 补」
- 行高 40px，hover 出 `--bg-sunken` 底；点击概念节点 → 右侧滑出节点详情面板（该节点卡片列表 + 资料列表 + 笔记）
- 树缩进每级 20px；折叠态记忆在本地

**资料流 tab**：按时间倒序的资料条目（沿用首页文档条目样式），每条可显示「挂在：梯度消失」的归属小字

**头部进度条**：2px `--accent` 细条 + 小字统计（覆盖率=非空白节点/总节点）

**「整理地图」按钮**：触发主题 Agent 重排地图（job），执行中按钮转圈小字「整理中…」，完成后地图平滑刷新

**提议开主题的提示条**（首页顶部，非弹窗）：
```
💡 你最近 6 条资料都关于「Rust 生命周期」。[开个主题] [忽略]
```
`--anchor` 淡底，radius-md，一周不点自动消失

## 7. 动效
- 卡片翻面：rotateY 180° 300ms ease
- 锚点面板滑出：translateX 200ms ease-out
- 主题切换：全站 color/background 150ms 过渡
- 其他 hover 变色 100ms；无入场动画；尊重 prefers-reduced-motion

---

## 8. 文案语气
- 句子小节、口语、主动语态：「扔进去，它来消化」「先自己想，想起来了再翻」
- 空状态是邀请：「这张纸还是空的，写点什么吧」
- 报错说人话+给出路：「这段话没切出卡片，可能太短了——多贴一点上下文试试」
