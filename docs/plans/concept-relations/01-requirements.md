# 概念与关系：需求方案

日期：2026-10-15。版本：v2（文章学习工作区与双视图）。状态：待评审的完整方案；本次仅交付文档，不启动开发。

关联：[技术方案](02-technical-design.md) · [开发任务计划](03-development-tasks.md) · [交互原型](../../design/prototypes/concept-relations.html)

## 1. 要解决的问题

用户围绕一个领域阅读多篇文章时，会接触大量术语。单篇文章中的解释和卡片容易分散、重复；仅记住定义也不能保证理解概念间的组成、执行、评判、依赖和区别关系。

目标是让阅读积累为一个有出处、可修订、可复习的概念网络。用户既能查清一个概念，也能讲清它与其他概念的联系。关系与概念同等重要，有自己的语义、解释、例子、出处和学习记录。

用户已确认的方向：保留现有原型的关系展示；支持阅读选词、选段、主题内手动创建；增加 Agent 针对当前文章的名词智能生成概念及关系；接入定期复习。本轮进一步确认：文章内可查看、编辑和管理概念关系；采用可聚焦的双视图工作区，支持同页对照与独立状态恢复。具体空间阈值需原型验证，以下默认值是开发起点。现有 HTML 原型仅体现早期关系展示，尚未实现本轮双视图设计。

## 2. 产品形态与边界

文章是概念学习与管理的主要入口，主题页负责跨文章汇总。文章正文旁设置统一学习工作区，承载文章脑图、概念与关系两个独立视图，支持聚焦其中一个或同时对照；概念区同时提供关系图与索引。练习进入已有每日复习。沿用纸上学习视觉和同一文章工作台。

| 对象 | 用户理解 | 与既有对象的区别 |
| --- | --- | --- |
| 概念 | 在一个领域语境下有稳定含义的知识条目 | 同一概念可有多篇出处、多张练习卡 |
| 关系 | A 与 B 的一条可读陈述 | 有方向和谓词；不只是两点间画一条线 |
| 出处 | 支持解释或关系的原文片段 | 保留文章、引用及定位信息 |
| 练习卡 | 用于回忆一个概念或一条关系 | 继续承载题目、反馈和复习间隔 |
| 文章脑图 | 一篇文章的章节与阅读结构 | 不直接改写为主题概念网络 |
| 主题大纲 | 领域的组织框架 | 原有大纲与卡片图谱继续保留 |

首版每个概念属于一个主题；主题间同名词不自动合并。文章无需修改原有归属即可被作为某主题概念的出处。首版 Web 和其桌面壳开放创建、生成、展示；移动端保留既有阅读及普通文本练习能力，新建概念专用界面后续安排。

## 3. 关键用户流程

### R1：选词收为概念

1. 在文章选中术语，点击「收为概念」。预填名称、所选原文、当前主题；没有主题时选择已有主题或新建一个。
2. 用户可直接填写解释保存；「智能补全」按当前文章上下文生成解释及关系建议，不要求配置 AI 才能手动创建。
3. 显示同主题的同名、别名候选：补充已有概念，或明确选择「另一个含义」新建。相似词不会被静默合并。
4. 推荐关系列出另一端概念、谓词、解释及证据；允许取消、改向、改词或添加关系。
5. 保存概念与勾选关系；默认仅收录。可另行选择「加入复习」。

解释可先留空并标「待补充」。没有可靠联系时允许孤立概念，不强迫 AI 为连图而编造关系。

### R2：选段梳理概念与关系

选择一个或多个连续正文块，点击「梳理概念与关系」。Agent 以选段为主要证据，必要时读邻近上下文；预览显示新增、沿用、补充、待确认四类结果。用户确认之后一次合入主题。

取消某个新概念后，依赖它的关系默认取消；用户也可以将端点重绑定到已有概念。不能提交悬空关系。

### R3：Agent 针对当前文章智能生成（核心）

入口一：文章顶栏「生成概念与关系」。入口二：当前文章的 Agent 对话中说“梳理本文名词，生成概念和关系”。两个入口使用同一流程和同一结果预览。

1. 明确当前文章和目标主题。当前主题可默认选择；缺少目标时内联选择，不让 Agent 随意开主题。对话没有文章上下文时要求指定文章。
2. Agent 读取文章中已保存的文本，识别重要领域术语，提炼文章语境内的定义、别名、例子及关系，并检索目标主题已有条目。
3. 显示可恢复的生成进度：读取正文、提取概念、整理关系、核对出处；任务可在后台继续，失败可重试。
4. 返回候选概念网络：每个节点和关系均可查看依据、编辑、取消、选择复用已有条目。
5. 用户点击「收录所选」。系统校验变更、去重并一次保存，给出新增与补充数量。
6. 可继续选择少量重要概念/关系加入复习；未选择的条目不会产生待复习负担。

智能生成的具体规则：

- 首版由用户主动触发，不在每次导入或打开文章时自动运行。
- 默认推荐 5–12 个核心概念、最多 20 条关系；短文可以更少或为零。单批硬上限 30 个概念、60 条关系，避免巨型预览。
- 区分「原文支持」「推断待确认」「用户补充」。推断关系默认不勾选，必须显式确认，收录后仍保留推断标记。
- 不以术语在同一段出现作为有关系的充分依据；不强求所有名词均被抽取。
- 先读取当前文章，首版不自动联网补全。文章没有说明的内容不伪装成原文事实。
- 长文按块处理并显示已覆盖/未覆盖段落；首版单任务最多 60,000 个 Unicode 字符，超限时让用户选择章节或分批，禁止静默截断。
- 尚未提取文本的 PDF、图片提示先完成提取；PDF 有文本时支持生成，出处可降级为页码和原文摘录。
- 文档有未保存修改时先完成保存，再锁定本次生成的正文版本。保存失败则不提交生成任务。

### R4：在文章和主题中手动维护

文章概念区和主题页共用「新建概念」「连接概念」。文章内创建或收录的条目同时关联本文；支持「从本文移除」且不删除共享知识。选中概念后可「添加关联概念」，搜索已有节点或同时新建另一端。关系编辑器呈现「源概念 → 谓词 → 目标概念」，附方向预览、解释、例子和可选出处。

支持修改名称、别名、解释、语境、关系及出处，支持归档。首版不提供两个已存在概念的一键破坏性合并；候选阶段可复用已有概念。归档概念会同时隐藏其关系并暂停相关练习，确认时说明影响。恢复概念后，关系及练习须按各自状态显式恢复，防止误重启。

### R5：阅读关系网络

- 默认显示当前主题最近浏览或核心概念的局部关系；可切全局总览与索引。
- 点概念展示解释、例子、所有相邻关系和出处；点关系展示可读陈述、语境、例子、出处和练习状态。
- 箭头与谓词必须表达同一方向，例如 Task「可以进行多次」Trial；组成关系约定整体指向部分。
- 支持按名称/别名搜索、只看本文、只看待确认、只看已加入复习。
- 大图默认最多展示 50 个节点，继续展开邻居；列表仍可访问全部条目。手机宽度使用可滚动图和完整列表，详情不依赖悬停。
- 「有出处/已收录」和「复习表现」分别表达。首版展示未加入、未练习、最近反馈、到期时间，不虚构掌握百分比。

### R6：概念与关系复习

一个概念或关系可以关联多个题型，每个练习独立排期。首版支持概念回忆、关系辨析和场景判断，复用现有卡片题型，默认每次只推荐一个练习。后续再考虑图上挖空。

用户可手写题目；智能出题提供候选题和答案，确认后加入每日队列。默认每日上限、间隔算法、三档反馈与现有复习一致。重复点击加入同一目标同一题型不会创建重复练习。

定义题答对不自动表示关系掌握；关系答对也不替其他题目计分。题面揭晓前不显示包含答案的关系图。翻面后可查看关系和原文，再回到原练习。修改目标内容会标记旧练习「内容有更新」并暂停；用户更新题面、答案且确认后重置该练习排期，历史反馈保留。

### R7：文章学习工作区与双视图

同一页面提供三个工作模式：

| 模式 | 展示 | 主要任务 |
| --- | --- | --- |
| 专注文章结构 | 正文＋脑图 | 按章节阅读、整理划线与卡片 |
| 专注概念联系 | 正文＋概念区 | 创建、编辑、确认候选、梳理关系 |
| 对照学习 | 正文＋脑图＋概念区 | 对照知识结构及其在文章中的位置 |

两个图不合成一张混合画布：文章脑图表达层级，概念图表达带类型和方向的联系，整个概念图不限定为 DAG，合法跨类型环可以存在。首版不把 dependency 作为可执行前置调度，因此不引入全局无环约束；若未来增加严格前置类型，再单独定义环检测。

首次打开文章沿用脑图；用户主动触发概念生成时打开概念区，默认聚焦概念，已经处于对照模式则保持对照。普通笔记本对照模式优先正文在左、两图在右上下排列，宽屏允许横向三栏。可调整分隔比例、临时放大某个视图、返回之前布局。尺寸不足时降级为单视图，保留对照偏好，恢复空间后恢复布局；窄屏不强行压缩成三栏。最终断点由任务原型验证后校准。

详情在所属视图内展开，不额外挤出第四个常驻栏。生成结果到达只显示提示，不抢焦点、不自动切模式、不重置现有画布。

### R8：本文语境与共享知识

「本文概念」是共享概念的文章范围视图，不是文章私有副本。默认只呈现本文关联概念、本文收录的关系及当前文章的解释与出处；仅有两个概念同时出现不自动证明它们之间某条关系来自本文。由关系端点带出的概念标为「关系上下文」，其他文章联系按需展开并标明来源。

详情区区分「本文的说法」「概念定义」「其他文章补充」。补充本文解释不改共享定义；编辑共享定义明确提示它影响其他文章与相关练习。文章可以关联多个主题中的知识，概念区显式选择当前主题范围，首次默认文章主题；主题没有对应条目时提供关联已有概念的入口。

### R9：卡片共用与双向联动

概念节点不是复习卡。概念条目、关系条目和学习卡片拥有不同身份；同一张学习卡可以在文章脑图中出现、关联知识目标、进入每日复习，始终只有一个 cardId 和一份排期历史。

卡片可关联多个涉及概念/关系用于导航，但首版至多指定一个主要练习目标，其他关联不继承该卡的反馈。允许显式把已有脑图卡片绑定为练习，无需复制；绑定本身不改变它已有的复习状态。未入队的卡片仍须显式加入。新练习卡可由用户挂到本文现有脑图位置，不自动重排脑图。操作步骤、经验类卡片无需强制概念化。

- 选脑图卡片：概念区高亮相关概念/关系。
- 选概念/关系：脑图标记所有已关联的卡片、划线位置；多个位置用列表选择。
- 默认只高亮，不移动另一图、不展开其分支、不同步缩放。被折叠/过滤或未加载的目标显示数量及「定位」入口。
- 用户点击「定位」才按需加载、展开路径和平移；保留定位前状态并提供返回。找不到对应位置时说明原因，不创建虚假脑图节点。
- 卡片编辑在各处同步，复习反馈不重复。解除导航关联不删除卡片或复习历史。

### R10：学习状态连续性

切视图、专注/对照切换、详情打开关闭、看出处、去复习再回来，都应保留阅读和操作上下文。

| 状态 | 保留内容 |
| --- | --- |
| 正文 | 段落/页码锚点、锚点内偏移、阅读位置 |
| 脑图 | 平移、缩放、展开分支、选中节点 |
| 概念区 | 平移、缩放、聚焦对象、图/列表模式、搜索及过滤 |
| 详情与列表 | 目标、滚动位置 |
| 工作区 | 工作模式、两图排列、分隔比例、临时放大前布局 |
| 编辑 | 候选勾选和未提交表单，切换不清空 |

同一会话跨路由和刷新恢复全部可恢复状态；重新打开应用恢复本机布局及视口，正式候选按服务端批次恢复。手动未保存表单至少在当前标签会话内恢复，跨会话不承诺自动保存。状态按用户、文章、主题范围隔离；从主题进入或直接进入同一篇文章可复用阅读位置，返回目的地仍由本次入口决定。

正文修改后优先找回原段落；节点变化后保留仍存在的焦点及附近区域，不机械恢复错误像素。新增节点不触发全图适配；只在首次无可用状态或用户点击「适应全部」时重置。目标删除时回到有效上下文并提示，不跳到其他文章。两个标签页互不强制同步视口。

## 4. 去重、语境和证据

同一主题内，相同名称/别名只触发匹配建议，用户决定是否同义。相同术语在不同框架中有不同含义时允许并列条目，以语境标签区分。新增文章补充出处与说明，不直接覆盖用户维护的主要解释。

关系以源、目标、类型、谓词、语境共同识别。相同关系新增出处；相反或不同口径关系并列呈现并提示差异，禁止自动折叠为一条结论。

出处保存文章标题快照、精确引文及原文定位。文章修改后无法定位时展示「原文已变化」并保留引文；文章删除后展示「来源不可用」，条目仍可阅读，不能跳转到其他位置冒充出处。

## 5. 范围与非目标

首版包含 R1–R10、候选预览确认、来源追溯、跨文章复用、手动维护、失败重试、权限隔离和新旧功能兼容。关系与概念都必须有完整创建到复习链路。

不包含：完整混合图、脑图上的局部关系浮层（后续增强）、全站自动扫描、跨主题全局本体、自动抓取外部知识、多人协作、自由画布编辑器、批量迁移所有历史卡片、自动合并已有条目、无需确认直接写入全部生成结果、全新复习算法、移动端完整概念编辑器。

| A3 | 确认所选内容后，节点和关系同时出现；取消端点不会留下悬空边 |

| A19 | 合法带环概念图可展示；两概念同时出现不引入其他文章的关系 |

## 7. 发布后的观察

记录触发到生成成功率、候选采纳/修改/复用比例、无证据结果比例、关系详情访问、关系练习完成率和反馈分布。采纳率只用于判断生成是否有用，不等同事实正确率。首版不承诺固定生成耗时；按文章长度、模型和任务队列展示真实进度。

验收先使用人工标注的短文、术语密集文、歧义文、无术语文、跨篇重复文和长文样本；重点检验是否保留正确关系和依据，而非生成的数量。

## 8. 方案取舍与演进验证

| 方案 | 价值 | 复杂度与决定 |
| --- | --- | --- |
| 完整混合图 | 一个空间看到全部 | 节点语义、连线和布局相互干扰；首版不做 |
| 脑图＋局部关系浮层 | 就地理解附近联系 | 适合阅读辅助，不适合完整维护；后续增强 |
| 独立视图切换并保留状态 | 清晰、省空间 | 是专注模式及窄屏降级方式 |
| 可聚焦的双视图 | 持续对照、不丢上下文 | 首版方向；以显式定位控制联动复杂度 |

演进顺序：共享知识和卡片引用 → 独立视图状态 → 可选双视图及高亮联动 → 后续局部关系浮层。布局可调整，不改变知识身份和引用结构。

在开发正式布局前，用同一篇文章和数据比较「可聚焦双视图」与「脑图＋局部联系」交互草图，完成找定义与出处、查跨章节出现、改关系返回阅读、确认新增内容、复习返回五类任务。观察寻找时间、误选次数、重新缩放/定位次数及对照使用时长。比较时两版均保留状态，避免用状态丢失掩盖布局问题。局部浮层只作验证，不默认纳入首版开发；宽屏/笔记本的排列和空间阈值根据结果校准，改变范围需再评审。
