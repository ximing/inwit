## 目标（apps/web，全部走 /api 代理，cookie 认证）
1. **登录/注册页**：简洁表单，成功后进主页；未登录路由守卫跳转
2. **捕捉页（主页，即对话框）**：
   - 顶部线程切换器：全部 / 各线程 / +新建线程（弹窗输入标题+可选目标）
   - 主体是聊天式时间线：每条消息是一条 capture，显示状态（消化中…/已消化出 N 张卡/失败）
   - 底部输入框：粘贴长文本，Cmd+Enter 发送 → POST /api/captures（带当前 threadId）
   - 消化中的消息每 3s 轮询状态直到 digested，然后展开显示生成的卡片（concept/example/易混点/标签）
3. **复习页**：
   - 进入显示今日进度（已刷/总数）+ GET /api/review/today
   - 抽认卡交互：先显示问题（取卡片第一道题或 concept 本身）→ 点击/空格翻面显示答案 → 底部三个按钮：忘了(red) / 模糊(yellow) / 想起来了(green) → POST feedback，自动切下一张
   - 刷完显示完成态 + 今日统计
4. **线程页**：线程列表（标题/目标/卡片数/创建时间）+ 归档操作
5. **设置页**：BYOK 配置管理（列表/新增/删除/设默认/测试连通），key 掩码显示
6. UI 风格：简洁现代，中文界面；可以用轻量 CSS（手写或 tailwind，选一个）
