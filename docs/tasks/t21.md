## 目标 1：反馈写 Memory
POST /api/review/:cardId/feedback 时，除现有逻辑外：把这次反馈追加到 memories（scope=user, layer=mastery, key=`card:<cardId>`, content={recent: 最近5次反馈+时间}，upsert）。这是给 Agent 读的上下文，不影响 SM-2。

## 目标 2：evolve 处理器（pi Agent，src/agent/）
payload: {cardId, reason: 'fuzzy'|'repeated_forgot'}
1. 工具：`read_card`（卡+题+复习状态+最近反馈）/ `write_questions`（已有）/ `split_card`（见下）/ `write_memory`（layer=mastery）/ `link_cards`（已有）
2. **reason=fuzzy**：Agent 读卡后从**不同角度**出一道新题（换题型：原来是填空就出判断或对比），write_questions 追加（旧题保留）。同时在 write_memory 记「这张卡第一次讲法没讲透，换了个角度」
3. **reason=repeated_forgot**：Agent 把卡**拆小**：`split_card(cardId, children: [{concept, example, confusion_point, anchor_text?}])` → 创建 1-2 张更小范围的子卡（source=agent，同 document_id），每卡出 1 道题、建 review_states（明天到期）、与原卡建 link(type=related, origin=agent, reason 写「由原卡拆小」)。原卡保留，write_memory 记录拆分原因
4. 执行明细照旧写 agent_executions.steps；用量记 llm_usage_logs

## 验收（真实链路）
- 建卡 → POST feedback=fuzzy → 等 evolve job done → 该卡多了一道不同题型的新题
- 另一张卡连续 forgot 两次 → evolve job → 出现 1-2 张子卡（明天到期、有相关边、原卡还在）
