# T20: Agent 提议开主题 + 收尾

工作目录 /Users/ximing/project/mygithub/inwit。读 docs/prd.md §2.6（主题可以由 Agent 提议诞生）和 design-system.md §6.5（提示条规范）。前置：T16–T19。

## 目标
1. **提议 job**（jobs type=topic, action=suggest）：
   - 触发：digest 完成一篇未归属文档后顺带检查（轻量），或手动 POST /api/topics/suggest-scan
   - 逻辑：进化 Agent 读未归属资料（近 30 天）标题+卡片概念，若发现 ≥4 条聚成一类且没有对应活跃主题 → 写一条建议 memories(scope=user, layer=profile, key=topic_suggestion_<slug>, content={title, reason, documentIds})
   - 幂等：同一主题建议不重复产生（key 去重）；被忽略的建议 30 天内不再提
2. **API**：
   - GET /api/topic-suggestions → 当前待处理建议
   - POST /api/topic-suggestions/:key/accept → 建主题 + 归属相关资料 + 自动触发 organize（生成初始地图）
   - POST /api/topic-suggestions/:key/dismiss → 标记忽略
3. **首页提示条**（design-system §6.5 规范）：--anchor 淡底 radius-md，「💡 你最近 N 条资料都关于「X」。[开个主题] [忽略]」，accept 后跳新主题页看地图长出来
4. **收尾**：
   - README 更新概念模型（四实体：资料/卡片/主题/关联）+ 新路由
   - docs/dev-log.md 追加 T16–T20
   - 全站文案终检：无"线程"残留、空状态统一 §8 语气
   - `pnpm -r typecheck && pnpm -r build && pnpm --filter @inwit/server test` 全绿

## 验收（真实 LLM）
- 往未归属池 POST 4-5 条同主题（如「Rust 所有权/生命周期」）资料并 digest → 触发扫描 → GET /api/topic-suggestions 出现建议 → accept → 主题建好、资料归属、初始地图生成
- dismiss 后再扫描不重复出现
- 首页提示条交互正常（明暗主题）
