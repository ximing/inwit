## 目标
主题详情页 /topics/:id 重构为地图主视图：
1. **头部**：主题名（衬线 xl）+ 目标一行 + 进度条（2px --accent）+ 小字统计（已覆盖 x/y 概念 · N 张卡 · 掌握 z%）+ 操作按钮：[整理地图] 次按钮（job 进行中转圈「整理中…」，轮询 job 状态）、[归档] 幽灵
2. **tab：地图 | 资料流**
3. **地图 tab**（核心）：
   - 可折叠大纲树：章节行（▾/▸ + --text-base 500 + 右侧 N卡·M资料 --ink-faint xs）→ 概念节点行（40px 行高，缩进 20px/级）
   - 状态点 10px 圆：covered 实心 --ok / learning 半满 --warn（CSS conic-gradient 或叠层实现）/ uncovered 虚线空心 --ink-faint + 节点名淡色 + 右侧幽灵按钮「让 AI 补」
   - 点击概念节点 → 右侧滑出节点详情面板（复用文档阅读页的侧滑面板模式）：节点标题、note、卡片列表（小卡，点击进卡片详情）、资料列表（点击进文档）
   - 折叠状态 localStorage 记忆
   - 空地图（从未整理过）：显示「还没有地图」+ 主按钮「让 AI 整理一张地图」（触发 organize job）
4. **资料流 tab**：时间倒序资料条目（复用首页文档条目组件），每条显示归属节点小字「挂在：梯度消失」（如有）
5. 主题列表页 /topics 也更新：每个主题条目显示覆盖率小进度条
6. 复习页复习的卡片若有 map_node，轻提示处顺带显示所属主题·节点路径（小字 --ink-faint）
