## 背景与总原则

产品模型收敛为一句话：**批注是「痕迹层」，脑图是「摆放层」，卡片是「学习层」，复习只认卡片**。

- 批注两个正交维度：锚点（有/无）× 内容载体（文本/图片/图文）。`kind` 的语义 = 锚点类型：`text`（正文选段）/ `pdf`（页+几何）/ `media`（截图区域）/ **`note`（无锚点，本任务新增）**。无锚点批注 = 「想法」：阅读时随手记的评论/思考/贴图。
- 现状裂缝：脑图的 `text`/`image` 孤儿节点（只在 canvas_nodes 表，无索引、无回收站、无 resurface、不可转卡）与「想法」是同一个概念的两个实现。本任务把它们**一次性归并进批注体系**，canvas_nodes 收敛为纯摆放层（逻辑上只剩 card + annotation 两种 member）。
- 转卡片、检索索引、resurface、回收站、脑图落位全部复用现有批注链路，不新造路径。`cardInputFromAnnotation`（packages/dto/src/card.ts:215-250）已为无 quote 场景预留逻辑（quote 空则不带 anchorText，imageKey 分支独立），先读它再动手。
- AI 纯手动：不做「AI 消化想法」入口。想法不进复习、不加 SM-2、不加 link 体系。

## 目标 2：Server——批注图片 key 拓宽 + note 链路接通

现状裂缝：批注 `imageKey` 只认 excerpt key（`isExcerptKeyFor`，前缀 `docs/<user>/<doc>/excerpts/`），而脑图图片与想法贴图用的是 doc-asset key（`users/<user>/doc-assets/`，`assertOwnedAssetKey`）。不拓宽则「想法贴图」与迁移后的图片节点都无法取图。

- 新增共享谓词（放 annotation 模块或 excerpt-logic 旁）：`isAnnotationImageKeyFor(userId, documentId, key)` = `isExcerptKeyFor(...) || (isAssetKey(key) && key.startsWith('users/<userId>/') && !key.includes('..'))`。
- `createAnnotation`（annotation.service.ts:79-105）：imageKey 校验换用新谓词；`quote: input.quote ?? ''`；kind 默认逻辑不动。
- `getAnnotationImage`（annotation.service.ts:107-118）：404 分支换用新谓词。
- `tryIndexAnnotation`：确认 quote 空时索引 note 内容；纯图片 note（note 为 ''）无可索文本时跳过不报错。补不了索引就日志降级，不阻断创建。
- resurface（annotations/resurface.ts）：挑选条件 `note <> ''` 天然排除纯图片 note，无需改动；确认 note kind 正常参与即可。
- `POST /api/documents/:id/canvas` 的 text/image 创建**保留可用**（兼容旧客户端），加注释标记 deprecated，新代码不再调用。

## 目标 5：存量一次性迁移（与目标 1 同一迁移文件，手写 SQL 追加在 drizzle 生成段之后）

幂等（`WHERE kind IN ('text','image')` 二次执行为空集）：

```sql
-- 文本节点 → note 批注（id 复用 canvas 行 id，无映射问题）
INSERT INTO "annotations" ("id","user_id","document_id","quote","note","kind","created_at","updated_at")
SELECT "id","user_id","document_id",'',"text",'note',"created_at","updated_at"
FROM "canvas_nodes" WHERE "kind"='text';

-- 图片节点 → note 批注（imageKey 为 doc-asset key，依赖目标 2 的取图拓宽）
INSERT INTO "annotations" ("id","user_id","document_id","quote","note","kind","image_key","created_at","updated_at")
SELECT "id","user_id","document_id",'','','note',"image_key","created_at","updated_at"
FROM "canvas_nodes" WHERE "kind"='image';

-- canvas 行改指批注（annotations 行与 canvas 行同 id；check 约束要求 text/image_key 置空）
UPDATE "canvas_nodes"
SET "kind"='annotation',"annotation_id"="id","text"=NULL,"image_key"=NULL,"updated_at"=now()
WHERE "kind" IN ('text','image');
```

- 迁移顺序：先重建 `annotations_kind_check`（含 'note'），再跑上述三段；同一迁移文件内自上而下。
- 注意核对 annotations 表实际列清单（schema.ts:275-307），缺失列（如 page_index 等 nullable）不列即走默认值；若 id 列 default 与显式插入冲突以显式值为准。
- 迁移后不做检索索引 backfill（存量文本节点检索价值低，新建的自然进索引）。
