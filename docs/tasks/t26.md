## 背景与总原则

T25 解决了批注「被找到」。本任务做剩下两层：

- **第二层「被引用」**：digest/chat/evolve agent 获得读取批注的只读工具——批注记录的是用户在哪停顿、在哪困惑，是切卡与问答最 authentic 的上下文；
- **第三层「被重访」**：周报汇总本周批注并做关联点评；新增 `annotation_resurface` 周期 job 挑「>14 天且未转卡」的批注，在今日页以 banner 推送，一键转卡。

核心原则：

- **用户上下文运行时拉取，不内嵌 prompt**：沿用「system prompt 写可调用 read_xxx + 工具返回 hint」的既定模式；
- **resurface 用确定性逻辑，零 LLM 调用**：挑选条件（>14 天、未转卡、有 note）是纯数据判断，语义极浅，不值得花 LLM 成本（系统兜底百炼敏感）；周报的批注点评由既有 weekly agent 顺带完成；
- **批注不进复习队列**：重访是「推送回看 + 一键转卡」，不是第二个 SM-2 队列；升级为卡片后才进入复习飞轮；
- **建议存储复用 memories 表**（仿制 topic suggestions：scope='user', layer='profile', key 前缀 + 部分唯一索引），零新表。

## 目标 1：agent 只读批注工具（新文件 apps/server/src/agent/annotation-tools.ts）

照 analyze-tools.ts:270-306 模板（TypeBox 非 zod、`toolResult(text, details)`、全部查询带 `eq(userId)`、payload 带 hint 指导 LLM 下一步）：

| 工具 | 行为 | digest | chat | evolve |
|---|---|---|---|---|
| `read_document_annotations` | 空参。digest 用 `session.documentId`；evolve 变体由 `session.cardId` 解析 documentId（卡片无文档则返回空数组）。返回 `[{kind, blockIndex, quote(截断), note}]`，hint：「批注是用户亲手标记的重点，有批注的块优先切卡；note 里的疑问可写成 confusion_point」 | ✅ | — | ✅ |
| `search_annotations` | `{ query }`，走 T25 的 `searchAnnotations` + 行回填（含 documentTitle），hint：「用户批注可作为回答上下文，引用时点明出自哪份资料」 | — | ✅ | — |

weekly 不给 LLM 工具——批注统计直接进 `read_week_stats`（目标 2），确定性 SQL 更便宜且周报必须全量覆盖。

注册点：`digestTools`（tools.ts:609-621）、`chatTools`（tools.ts:639-647）、`evolveTools`（evolve-tools.ts:556-563）各追加对应工具。

prompt 改动（agent/prompts.ts）：

- **非 agent job**：不加 AgentType、不写 agent_executions。

新模块 `apps/server/src/annotations/resurface.ts`（蓝本 topics/suggest.ts + weekly-enqueue.ts）：

- **去重**：按 `payload->>'date'` 查 pending/running/done（模板 weekly-enqueue.ts:31-50 findWeeklyJobsForWeek）；
- **挑选条件**：`createdAt < now - 14d`、`convertedCardId is null`、`note <> ''`（有思考痕迹才值得重访，纯划线不打扰），每用户每天 ≤3 条（createdAt 升序，最旧优先）；
- **存量兜底**：convertedCardId 为 null 时再做宽松匹配（同文档 + imageKey 相等，或同文档 + anchorBlockIndex 相等 + quote 相等）判定已转卡，避免对 T25 之前的老批注误报；
- **process**：挑中 → 写 memories（scope='user', layer='profile', key=`annotation_resurface_<date>`，唯一索引天然防并发双写）；无可挑则静默成功；
- **DTO**（packages/dto/src/annotation.ts）：`ANNOTATION_RESURFACE_KEY_PREFIX`、`annotationResurfaceContentSchema`（annotationIds 1-3 条 / status: pending|accepted|dismissed / acceptedCardIds?）、`annotationResurfaceSchema`（key/status/createdAt + 回填批注行：id/documentId/documentTitle/kind/quote/note/pageIndex）；
- **get**：读最近 pending，回填批注行，剔除已删/已转卡条目，空则惰性转 dismissed；
- **dismiss**：status='dismissed'；**accept**（server 直转，不调既有手动建卡 API）：事务内 ① 校验批注属于该用户且在该 suggestion 里 ② 生成卡片字段（与 dto `cardInputFromAnnotation` 同源）③ insert card + `insertInitialReviewState` + 回写 convertedCardId + memory content 标记 ④ 事务外 `tryIndexCard`；返回 `{ card }`。

端点（挂 annotation.routes.ts）：`GET /api/annotation-resurface`、`POST /api/annotation-resurface/:key/dismiss`、`POST /api/annotation-resurface/:key/accept`（body `{ annotationId }`）。

## 明确不做（本任务范围外）
