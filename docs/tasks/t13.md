# T13: tiptap 编辑器 + 文档主页 + 快捷捕捉条

工作目录 /Users/ximing/project/mygithub/inwit。读 docs/design-system.md（§5 编辑器、§6.1、§8）和 docs/prd.md §2.6。前置：T11 的 documents API、T12 的设计 tokens 已完成。

## 目标
把产品主界面从"聊天时间线"改为"文档为中心"。

## 要求
1. **tiptap 编辑器**（/editor/:id 和 /editor/new）：
   - 依赖：@tiptap/react @tiptap/starter-kit @tiptap/pm tiptap-markdown（md 序列化），如需 placeholder 用 @tiptap/extension-placeholder
   - 纸面样式严格按设计系统 §5 编辑器条：radius-lg、padding 48/56、max-width 800、衬线正文 17px/1.8
   - 功能：标题（文档首行 H1 或独立标题输入，选一个并说明）、加粗/斜体/标题/列表/引用/代码块；选中文本浮动工具条；⌘S 保存
   - 保存：PUT /api/documents/:id {title, contentMd}（server 补这个接口，如果没有的话）；自动保存防抖 2s + 保存状态指示（保存中/已保存 HH:mm）
2. **文档主页（/ ，替换现有捕捉页为默认首页）**：
   - 顶部：快捷捕捉条（§5 规范）：单行输入「扔一句话进来，或以问号结尾问 AI」+ 问AI/扔进去
     - 扔进去 → POST /api/documents {contentMd, threadId?} → toast「已收下，消化中」→ 列表乐观插入
     - 问 AI → 走 /api/chat → 完成后该文档条目显示回答摘要 + 卡片数（轮询）
   - 快捷条下方：「写文档」次按钮 → /editor/new
   - 文档列表：按设计系统 §6.1——不是卡片堆叠，是细线分隔的条目：衬线标题 + 一行元信息（N 张卡 · 相对时间 · 线程名），点击进入阅读页
   - 消化中的条目：标题旁小字「消化中…」每 3s 轮询直到 digested
3. **线程切换器**保留在快捷条右侧或列表上方（沿用现有交互，套新视觉）
4. 旧聊天时间线路由 /captures 删除或 301 到 /，相关组件清理
