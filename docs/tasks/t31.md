# T31: 概念图选中节点原地展开信息卡，详情浮层退为二级入口

工作目录 /Users/ximing/project/mygithub/inwit。前置阅读：apps/web/src/features/concepts/concept-graph.tsx（SVG 图，节点是 pill rect+text，选中仅加 class）、concepts.service.ts（`select` :326 目前选中即拉详情）、concepts-panel.tsx（:166 详情浮层渲染点）、concept-detail.tsx、concepts.css（`.concept-detail` :506 绝对定位右上角浮层；`.concept-graph-wrap` :194）。

## 背景

点图节点/边立即弹出右上角详情浮层（300px、最高撑满），挡住大片画布；不弹又看不到任何信息。改为：**点节点 = 选中 + 在节点旁原地长出一张跟随图的轻信息卡**（名称/语境/别名/定义/例子 + 邻居关系 chip，全部来自已有 props，零新增请求）；需要出处、编辑、练习、归档时点卡片上的「详情」才打开现有 `ConceptDetailPane` / `RelationDetailPane` 浮层。关系边同理：点谓词 label 在边中点长出轻卡。

已确认决策（不要再提问、不要翻案）：
- 卡片位置跟随节点（随平移/缩放移动），**大小不随 zoom 缩放**（屏幕字号恒定）。
- 卡片放邻居关系 chip（指出 `谓词 → 邻居名` / 指入 `邻居名 → 谓词`），点 chip 直接选中邻居、卡片换锚点。
- `ConceptDetailPane` / `RelationDetailPane` 组件本身不动，浮层样式不动；只是打开时机从「选中即开」改为「点详情才开」。
- Esc 分层：详情开着先关详情（保留选中卡），再按才取消选中；点空白仍整体取消选中。

## 目标 1：service 拆分「选中」与「详情」

`apps/web/src/features/concepts/concepts.service.ts`：

- `select(target)` 改为**同步轻操作**：`this.selected = target; this.detail = null; this.detailLoading = false;`，不发请求。
- 新增 `async openDetail(target?: ConceptTarget)`：有 target 先 `this.select(target)`；对当前 `this.selected` 拉 `api.getConcept` / `api.getConceptRelation`（404 → 清 selected；错误文案沿用 '详情加载失败'）。
- 新增 `closeDetail()`：只清 `detail`。
- `boot` :209 的 `await this.select(this.selected)` **删除**（`restoreDocumentView` 已恢复 selected，卡片自然出现；不再回拉详情）。
- `expandNeighbors` :438 改同步 `this.select(...)`（展开后焦点节点出卡，不再弹详情）。

调用方同步：
- `concepts-panel.tsx`：图 `onSelectConcept/onSelectRelation` → `service.select(...)`；列表项点击 → `void service.openDetail({kind:'concept', id})`；详情 `onClose` → `service.closeDetail()`；Esc effect 改为常挂：详情开着 → `closeDetail()`，否则有选中 → `select(null)`。
- `concept-detail.tsx` :141 关系跳转 → `void service.openDetail({kind:'relation', id})`。
- `concept-practice-dialog.tsx` `refreshDetail` → `await service.openDetail({kind: targetKind, id: targetId})`。

## 目标 2：卡片定位纯逻辑 + 测试

新 `concept-card-logic.ts`：`placeConceptCard(anchor, stage, card, gap=12)` → `{left, top, side, caret}`。anchor/card 均为屏幕 px 矩形（relation 用边 label 点的零宽矩形）。规则：优先右侧（anchor 右缘 + gap），放不下降级左侧，两侧都不行（窄屏）降级下方，再不行上方；垂直/水平方向以 anchor 中心对齐并 clamp 到 `[8, stage - card - 8]`；`caret` = anchor 中心在卡片边缘上的偏移（px）。配 `concept-card-logic.test.ts`：右侧够 → right；右溢出 → left；窄 stage → bottom；下方溢出 → top；clamp 与 caret 计算。

## 目标 3：图内卡片层

新 `concept-card.tsx`：`ConceptNodeCard` / `ConceptRelationCard`。内容：
- 节点卡：名称（serif 15px 600）+ 语境、别名（`别名：a、b`）、定义（完整，卡内滚动）、例子、邻居 chip 区、底部右对齐「详情」按钮（accent 文字按钮）+ 右上角 × 关闭。
- 关系卡：`A → 谓词 → B` 标题、语境、解释、例子、详情按钮 + ×。
- 卡片 useLayoutEffect + ResizeObserver 自测量尺寸，未测出前 `visibility:hidden`；`onWheel` stopPropagation（wrap 上的 wheel 会平移图）；宽度 300px、max-width/max-height 由 CSS clamp 到 wrap。
- `concept-graph.tsx`：wrap 内 svg 之后渲染卡片层。世界→屏幕换算用 `viewMeet(stage, viewBoxSize(world, zoom))`：`sx = (wx - viewport.x)*scale + offsetX`。新 props：`onOpenDetail?(): void`、`detailOpen?: boolean`（详情开着时卡片隐藏）。锚点：节点=layout box；关系=drawnEdges 里该 relation 的 label 点。帮助浮层「Esc 关闭详情」改「Esc 先关详情，再收起信息卡」。
- `concepts-panel.tsx` 给图传 `detailOpen={service.detail !== null}`、`onOpenDetail={() => void service.openDetail()}`。
