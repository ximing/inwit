## 目标
1. **chat API + 问答 Agent**：
   - POST /api/chat {question, threadId?} → 写 captures(type=chat, raw_content=question) + jobs(type=chat) → 立即返回 captureId
   - worker 的 chat 处理器：pi Agent，tools=[search_cards（走检索 pipeline）, write_cards, write_questions]；系统提示：先检索用户已有卡片避免重复，用中文清晰回答，回答后把知识点自动整理成 1-3 张原子卡
   - 回答文本写回 captures（加 answer 字段或新列，如缺列就 drizzle 加迁移）→ status=digested
   - GET /api/captures/:id 能拿到 answer
2. **前端**：捕捉页输入框即问即答——如果内容以问号结尾或用户点「问 AI」按钮，走 /api/chat；回答以 AI 消息气泡展示在时间线，下方挂自动生成的卡片（可点击展开）
3. **收尾**：
   - root README.md：项目简介、架构图（照 prd）、启动步骤（pnpm install / migrate / dev / worker）、环境变量说明
   - 把 docs/tasks/ 的 prompt 文件保留（它们是开发历史），但 t*-report.md 内容归档整合进 docs/dev-log.md
   - `pnpm -r typecheck && pnpm -r build && pnpm --filter @inwit/server test` 全绿
