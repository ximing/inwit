## 目标
1. **聚合 API**（server，挂认证）：
   - GET /api/admin/jobs?status=&type=&page= —— 任务列表（已有可复用 T4）
   - GET /api/admin/usage/summary?days=30 —— token 用量聚合：按 provider/model/capability 分组 + 按天趋势 + 总成本估算（drizzle sql 聚合 llm_usage_logs）
   - GET /api/admin/executions?agentType=&status=&page= —— agent 执行列表（关联 job、capture、user）
   - GET /api/admin/executions/:id —— 执行明细，含 steps 数组逐步展示
2. **后台页（apps/web，路由 /admin）**，三个 tab：
   - **任务队列**：表格（类型/状态/尝试次数/创建时间/耗时/错误），状态筛选，failed 可点重试
   - **Token 用量**：顶部汇总卡片（总 tokens、chat/embed/rerank 分布、成本估算）+ 按天趋势图（手写 SVG 简单折线即可，不引重型图表库）+ 按模型分组表
   - **Agent 执行**：执行列表（agent 类型/状态/步数/耗时/产出摘要），点开行下钻展开 steps 时间线（每步 tool 名、入参摘要、结果摘要、耗时）
3. 顶部导航加「后台」入口
