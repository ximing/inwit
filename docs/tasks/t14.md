## 目标 1：消化 Agent 升级（src/agent/）
1. `write_cards` 入参每张卡增加 `anchor_text`（**必须从原文逐字引用**的一句话/一段话，prompt 里明确要求逐字 quote，不允许改写）和 `anchor_block`（第几段，从 1 计）
2. 新 AgentTool `link_cards(cardId, targetCardId, type, reason)`：agent 切卡后，对每张新卡调 `search_user_memories` 找相关旧卡，建立 card_links（type: same_concept|confusable|prerequisite|related，origin=agent）。系统 prompt 里要求：只对置信度高的关联建边，每张新卡最多 3 条边，并在 reason 里写人话理由
3. chat agent 的回答若引用已有卡片，也用 link_cards 建边
4. 关联提示（PRD「这和你第 3 周学的 X 是一回事」）：digest 完成时，若建了 same_concept 边，在 document 的 answer 或专门字段写一句提示（前端展示用）

## 目标 2：文档阅读页（/doc/:id）
1. 只读渲染 markdown（tiptap read-only 或 markdown 渲染器，与 T13 编辑器视觉一致：衬线、680px 行长、纸面）
2. **锚点高亮**：cards.anchor_text 命中的原文片段包 `<mark class="anchor">`（批注黄底 + 左 2px 竖条，按设计系统）；多卡同段都要支持。实现建议：渲染后对文本节点做精确字符串匹配包裹（注意跨节点情况，做不到就降级为段落级高亮并在报告说明）
3. 点击锚点 → 右侧滑出卡片面板（200ms translateX，§7）：卡片完整内容（概念/例子/易混点/标签/自测题）+「查看详情」链接；再点空白处收起
4. 页面顶部：标题、元信息（线程/时间/卡数）、[编辑] 进 /editor/:id
5. 若 document.answer 有内容（chat 文档），在文首展示 AI 回答块
