## 目标 1：检索 pipeline（src/retrieval/）
1. embedding.ts：百炼 multimodal-embedding 接口，模型取 env EMBEDDING_MODEL(qwen3-vl-embedding)，维度 EMBEDDING_DIMENSIONS(2560)，单批≤20 条，带 telemetry 写 llm_usage_logs(capability=embed)
2. rerank.ts：百炼 text-rerank，模型 RERANK_MODEL(qwen3.7-text-rerank)，写 llm_usage_logs(capability=rerank)
3. qdrant.ts：连接 .env 的 QDRANT_URL/QDRANT_API_KEY；collection `inwit_cards_dev`（NODE_ENV=production 时 inwit_cards_prod），2560 维 cosine；启动时 ensure 存在；payload 索引 user_id/card_id
4. meili.ts：index `inwit_cards_dev`（prod 同理），filterableAttributes: user_id, card_id, tags
5. pipeline.ts：
   - indexCard(card)：embedding(concept+example+confusion_point) → upsert qdrant(payload: card_id,user_id,tags) + meili 文档
   - deleteCard(cardId)
   - searchCards(userId, query, limit)：Qdrant 语义召回 ∪ Meili 关键词召回（都强制 user_id 过滤）→ RRF 融合 → rerank 精排 → 返回 card_ids 有序列表
6. scripts/test-retrieval.sh 或 vitest：用假卡验证 index→search→delete 全链路通

## 目标 2：消化 Agent（src/agent/，pi-agent-core）
实现 T4 留下的 digest 处理器：
1. 定义 AgentTools（全部真实落库）：
   - read_capture(captureId)
   - write_cards(cards: [{concept, example, confusion_point, tags}]) —— 写 cards 表 + 触发 indexCard
   - write_questions(cardId, questions: [{type, question, answer}]) —— 每卡 1-2 道，题型 cloze|compare|judge
   - search_user_memories(query) —— 调检索 pipeline，用于关联已有概念
   - attribute_thread(captureId, threadId, reason) —— 软归属（capture 无 threadId 且与某活跃线程高度相关时）
2. digest 处理器：读 capture → resolveModelFor(userId) → 构造 pi Agent（系统提示词：把内容切成原子卡片，一条概念+一个例子+一个易混点，为每卡出题；若内容与已有记忆高度相关，指出关联）→ 跑 agent loop → 全部成功：capture.status=digested，job done
3. **执行明细**：agent 每步 tool 调用记录到 agent_executions.steps（tool/入参摘要/结果摘要/耗时），执行结束写 agent_executions(status, started/finished_at)；LLM 用量写 llm_usage_logs(capability=chat)
4. 失败处理：LLM 错误 → job 重试（T4 机制）；卡片为空 → capture.status=failed 并记原因
