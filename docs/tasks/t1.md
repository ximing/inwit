# T1: inwit monorepo 脚手架

你在 /Users/ximing/project/mygithub/inwit（git 仓库）中工作。先读 docs/prd.md 了解产品。

## 目标
搭建 pnpm monorepo，结构：
```
inwit/
├── apps/
│   ├── server/    # Fastify 5 + TypeScript + drizzle-orm（端口 3020）
│   └── web/       # Vite + React 19 + TypeScript（端口 5190）
├── packages/
│   └── dto/       # 前后端共享 zod schema 与类型，包名 @inwit/dto
└── docs/
```

## 要求
1. pnpm-workspace.yaml 覆盖 apps/* 和 packages/*。root package.json 提供 `dev`（并行起 server+web）、`build`、`typecheck` 脚本（用 pnpm -r，不引入 turbo）。
2. **apps/server**：
   - ESM ("type":"module")，tsx watch 开发，tsc 构建
   - 依赖：fastify@^5、@fastify/cors、@fastify/cookie、drizzle-orm、pg、zod、dotenv、argon2、jsonwebtoken
   - src/config.ts：用 zod 校验环境变量（参考 /Users/ximing/project/mygithub/vital/apps/server/src/config.ts 的写法），dotenv 加载 apps/server/.env（已存在，不要修改、不要把内容提交到任何会被 git 跟踪的新文件）
   - src/app.ts 组装 fastify 实例，src/index.ts 启动；GET /health 返回 {ok:true}
   - src/db/：pg Pool + drizzle 实例（PG_SSL=false 时不传 ssl）
   - drizzle.config.ts 就位（schema 下任务写）
3. **apps/web**：
   - Vite + React + TypeScript，状态管理用 @rabjs/react（先读 /Users/ximing/.claude/plugins/cache/rab/rab/9.0.0/skills/rab-react/SKILL.md 学习用法，示例在同目录 examples/ 或该仓库 packages/）
   - vite server.proxy 把 /api 代理到 http://localhost:3020
   - 极简布局占位：顶部导航（捕捉 / 复习 / 线程 / 后台）+ 路由（react-router）
4. **packages/dto**：zod  schemas 占位（User、Capture、Card 等类型先建文件，字段下个任务定），tsup 或 tsc 构建出 ESM+d.ts，server/web 通过 workspace:* 引用。
5. 全部 TypeScript strict。

## 验收（必须逐条跑通再结束）
- `pnpm install` 成功
- `pnpm -r typecheck` 全绿
- `pnpm -r build` 全绿
- 启动 server（pnpm --filter @inwit/server dev）后 `curl localhost:3020/health` 返回 {"ok":true}
- 启动 web（pnpm --filter @inwit/web dev）后 `curl -s localhost:5190 | grep -q '<div id="root"'`

完成后把结果简报写入 docs/tasks/t1-report.md（做了什么、验收输出摘要、遗留问题）。
