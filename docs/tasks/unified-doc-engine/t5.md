# T5：csi 端到端回归（真实 Chrome）

由编排者（Claude）用 csi daemon 驱动真实浏览器执行，grok 只负责修复发现的问题。回归清单：

## 环境

- dev server 已在跑：web http://localhost:5190（/api 代理到 server :3020）；worker 按需另开。
- csi：`POST http://127.0.0.1:10088/command`，body `{"action","args","session"}`，session 固定用 `doc-engine-regression`（已存在）。

## 回归清单

1. **编辑器 JSON 往返**：新建文档 → 输入多段落 + 标题 + 列表 + 图片 → 等防抖保存 → 刷新页面 → 内容/结构完全一致（截图对比）。
2. **划词标注**：选中一段文字 → 建标注（写 note）→ 正文出现高亮；侧边栏出现条目；点击条目 → 对应区域激活高亮。
3. **锚随编辑移动**：在标注文字的**前面**插入/删除若干字符 → 保存 → 刷新 → 标注高亮仍精确罩住原文（不错位、不消失）。
4. **部分删除**：删掉被标注文字的一半 → 高亮收缩到剩余部分；侧边栏条目的 quote 快照仍是原文。
5. **整段删除**：删掉全部被标注文字 → 保存刷新 → 侧边栏条目变「原文已删除」置灰态。
6. **卡片高亮 + 多卡共锚**：同一段文字关联两张卡 → 高亮只一层底色；分别点两张卡 → 都能完整激活高亮同一区域（重叠完整覆盖）。
7. **标注与卡片重叠**：标注范围与卡片锚范围交叠 → 常态底色不加深（并集）；点击重叠区 → 回调带出双方 id。
8. **digest 产卡锚定**（需 worker + LLM key）：paste 一篇有内容的文档 → 等 digest 完成 → 卡片出现在右侧栏 → 正文相应位置有高亮（补打 mark 生效）；点击卡片 → 激活高亮。
9. **PDF 导入分页**：导入多页 PDF（或带 `---` 分页的 md）→ 阅读视图出现分页节点视觉；PDF 标注（如已有功能入口）页码语义正常。
10. **粘贴剥离**：复制带标注的文字粘贴到文档另一处 → 粘贴处不出现实体高亮（mark 被剥掉）。
11. **检索/agent 文本派生**：paste 文档后触发 digest/chat 问答正常（派生文本管道工作）。

## 执行方式

- 每个用例：navigate → snapshot → act → wait → screenshot 留证到 `docs/tasks/unified-doc-engine/shots/`。
- 发现问题 → 记录现象+复现步骤 → 起 grok 修复 session（resume 对应任务的 session-id）→ 修完重跑该用例。
- 全部通过后写 `docs/tasks/unified-doc-engine/t5-report.md`（每用例结论 + 截图清单）。
