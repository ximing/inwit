# T3：digest/selection agent 契约改造 — (blockIndex, quote) 结构化引用

先完整阅读 `docs/tasks/unified-doc-engine/PLAN.md`（重点第 1.6、4 节）和 `docs/rewrite/CONTEXT.md`。前置：T1（`@inwit/doc-schema`）、T2（contentJson 数据层）已完成。

本任务只改 `apps/server/src/agent/` 与相关 job/路由：**让 agent 用编号块视图看文档、用 (blockIndex, quote) 引用原文**，并删掉旧的模糊锚定链。不改 apps/web。

## 范围

### 1. digest agent 的文档输入改为编号块视图

- 找到 digest 链路（`src/agent/digest*.ts`、`tools.ts`，以及 job 分发处）里把文档内容喂给 LLM 的位置：改为 `blocksFromPmJSON(contentJson)` 产出的编号块视图，prompt 里明确格式，例如：
  ```
  [块 1 | 第 1 页] 第一段文本……
  [块 2 | 第 1 页] ……
  [块 3 | 第 2 页]（分页）
  ```
- prompt 文案同步改写：要求模型引用原文时必须给出 `blockIndex` + 该块内的精确 `quote` 子串（中文文案，克制书面）。

### 2. `write_cards` tool 参数改造

- 参数从（现状的 anchorText/anchorBlock 之类）改为 `{ concept, example, confusionPoint, blockIndex: int, quote: string }`（tags 等现有字段保持）。
- 建卡时：用 `@inwit/doc-schema` 的 `locateQuote(contentJson, blockIndex, quote)` 校验/定位；成功 → 卡片行写 `anchorText = quote`（快照）+ `anchorBlockIndex = blockIndex`；失败 → 卡片照建，`anchorText = quote`、`anchorBlockIndex = null`（无锚，不报错、不重试）。
- `apps/server/src/agent/anchors.ts` 的 `resolveAnchor`/`splitMarkdownBlocks`/`parseAnchorBlock`/`sliceIgnoringWs`/`inferBlockIndex`/`firstSentence` 整条降级链及其测试删除（`buildAssociationHint` 若在别处使用则保留或搬到使用处）。
- chat 转卡（`chat` job）与 evolve（换讲法/拆卡）若也写 anchor 字段，同一契约处理。

### 3. selection-cards（划词产卡）

- 路由/service 接收 DTO 已有的 `{ text, blockIndex }`：用 `locateQuote` 校验 `(blockIndex, text)`；selection agent 产出的每张卡继承该 `{blockIndex, quote}` 锚（agent 不需要自己定位，锚就是用户划的那块）。校验失败仍建卡、无锚。

### 4. 测试

- 新增纯逻辑测试：write_cards 参数 → 卡片行的锚字段写入（locate 成功/失败两路）、selection 锚继承。
- 受影响的既有测试全部更新；`pnpm -F @inwit/server test` 全绿。
