# T10: 修复 AI 回答的 Markdown 渲染

工作目录 /Users/ximing/project/mygithub/inwit。

## 问题
捕捉页里问答 Agent 的回答（captures.answer）以纯文本展示，markdown 语法原样露出（`###`、`**粗体**` 等）。见 docs/screenshots/01-capture.png 下半部分。

## 要求
1. AI 回答气泡用 markdown 渲染：加 `marked`（或 `markdown-it`，选一个轻量的）到 apps/web，渲染 captures.answer。注意 XSS：用 sanitize（如 dompurify）或确认所选库的安全选项。
2. 时间线里 AI 回答默认折叠/截断（比如超过 300 字显示"展开全文"），避免长回答刷屏——参考截图，长文把页面撑得很长。
3. 渲染样式：标题层级、加粗、列表、代码块、分隔线正常显示，字号与现有 UI 协调（样式加在现有 css 里）。
4. 同时检查捕捉页卡片展开（「展开」按钮）里如果也有 markdown 内容，一并渲染。

## 验收
- `pnpm -r typecheck && pnpm -r build` 全绿
- 起 server+web（端口 3020/5190），用 regression@inwit.dev / Regress2026! 登录，主页 AI 回答气泡的 `###`、`**` 不再原样露出，渲染为标题/加粗；长回答默认折叠带「展开全文」
- 验收完停掉进程
