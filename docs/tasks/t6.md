# T6: 复习队列（SM-2）+ 抽认卡 API

工作目录 /Users/ximing/project/mygithub/inwit。读 docs/prd.md §2.3。

## 目标
1. **SM-2 排期** src/review/sm2.ts：
   - 三档反馈映射 quality：forgot→1, fuzzy→3, remembered→5
   - 标准 SM-2：quality<3 重置 reps、interval=1 天、lapses+1；否则按 ease 递推 interval（1→6→round(prev*ease)）；ease 按公式调整、下限 1.3
   - 纯函数 + vitest 单测覆盖关键分支
2. **复习 API**：
   - 卡片创建时（T5 的 write_cards 钩子里补，或在本任务给 digest 流程补上）自动建 review_states（due_at=次日）
   - GET /api/review/today → 今日到期队列（due_at<=今天结束，按 due_at 升序），每项含 card + 其 questions + review_state；同时返回今日已刷/总数统计
   - POST /api/review/:cardId/feedback {feedback: forgot|fuzzy|remembered} → 写 review_logs + 按 SM-2 更新 review_states；fuzzy 时额外写一条 jobs(type=evolve, payload={cardId, reason:'fuzzy'})（evolve 处理器暂 stub 记日志即可）
   - GET /api/review/stats → 近 7 天回忆成功率（三档分布）、到期积压数
3. 迁移数据兼容：已存在的卡片若没有 review_states，提供 scripts/backfill-review-states.ts 补齐

## 验收
- 单测 `pnpm --filter @inwit/server test` 绿

- 连续 forgot 两次 → interval 重置为 1、lapses=2、evolve job 入队
- GET /api/review/stats 返回正确分布
