## 目标
1. **消化 Agent 升级**：digest 归属主题的文档时，新增工具：
   - `read_topic_map(topicId)`：读地图树（节点 id/标题/路径）
   - `place_on_map(cardId, nodeId | {newNode: {title, parentId?}})`：把新卡挂到已有节点，或创建新节点（不超过三级）再挂
   - prompt 要求：优先挂已有节点；没有合适节点才新建；章节结构保持稳定，不要每次 digest 都大改
2. **「整理地图」job**（type=thread→改名后应为 topic 类，复用 jobs 表）：
   - 触发：POST /api/topics/:id/map/organize → 入队 job(type=topic, payload={topicId, action:'organize'})
   - 处理器：主题 Agent 读主题目标 + 全部卡片概念 + 全部资料标题 + 当前地图 → 输出整理后的完整大纲树（重排/合并/改名/标空白节点）
   - **关键约束**：已有节点下的卡/资料挂载关系只能移动不能丢；空白节点（uncovered）是 Agent 主动规划的"该学还没学"的概念；整理动作写 agent_executions，地图变更前后快照存 memories(scope=topic, layer=topic_map)
3. **「让 AI 补」**：POST /api/map-nodes/:id/fill → 入队 job(action=fill) → Agent 为该空白概念生成 1-2 张入门卡（走 write_cards + 挂节点 + 出题），节点的 note 可写学习指引
4. digest 完成时若发生软归属到主题，同样走 place_on_map

## 验收（真实 LLM）
- 主题里 digest 一篇新文档 → 卡片出现在地图正确节点（或新建了合理节点）
- 手动触发 organize → 地图被整理（有章节结构），卡片零丢失（整理前后卡片数对账写进报告）
- 对空白节点 fill → 生成入门卡并进复习队列
