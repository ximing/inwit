# T12: 设计系统落地 —— tokens、明暗双主题、应用骨架重塑

工作目录 /Users/ximing/project/mygithub/inwit。**先完整读 docs/design-system.md，它是本任务的唯一设计依据，所有数值以它为准，禁止发挥。**

## 目标
把 apps/web 的视觉从"B 端后台"重塑为设计系统定义的「纸上学习」风格，支持明暗双主题。

## 要求
1. **tokens.css**：把设计系统 §2/§3/§4 全部 token 实现为 CSS 变量，`[data-theme="light"]` / `[data-theme="dark"]` 两组；组件里禁止出现写死的 hex/rgb（灰度也不行），全部走变量
2. **主题机制**：
   - ThemeService（rab Service）：`light|dark|system` 三态，写 documentElement.dataset.theme，localStorage 持久化，system 时监听 prefers-color-scheme
   - 侧边栏底部放日/月切换按钮；设置页加主题三态选项
   - 切换时 color/background 150ms 过渡（respect prefers-reduced-motion）
3. **字体**：§3 的字体栈和字号阶落地；文档/卡片正文用衬线类，UI 用无衬线
4. **应用骨架**（按 §6.1）：
   - 左侧 220px 细栏：`--bg-sunken` 底，选中项左侧 2px 朱批红竖条 + 淡底；顶部品牌区衬线「Inwit」+ slogan「扔进去，它来消化」
   - 导航项：文档 / 复习 / 线程 / 设置 / 后台（后台保留但降级到最后，文案改「任务与用量」）
   - 主区 `--bg-base`，内容 max-width 居中
5. **基础组件重切**（按 §5）：按钮（主/次/幽灵/危险）、卡片、标签、输入框、弹层、复习三档按钮、focus-visible 样式
6. 本任务**只改视觉与骨架**，页面功能逻辑不动；现有页面（捕捉/复习/线程/设置/后台）套上新 tokens 后能看、不破版即可，文档相关新页面 T13 做
