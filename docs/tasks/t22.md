# T22: 错误模式分析 —— 混淆对识别 + 对比专题生成

工作目录 /Users/ximing/project/mygithub/inwit。读 docs/prd.md §2.4、§2.7。前置：T21。真实 LLM，禁 mock。

## 背景
用户反复忘/模糊的卡片里藏着盲区。进化 Agent 要定期分析，找出"成对混淆"的概念，生成对比专题。

## 目标
1. **分析 job**：jobs type=evolve, payload={action:'analyze_patterns'}。触发方式：
   - POST /api/evolve/analyze（手动）
   - 某用户当日 forgot+fuzzy 累计 ≥3 次时自动入队一次（每日最多一次，payload 带日期去重）
2. **处理器逻辑**（pi Agent）：
   - 工具：`read_struggling_cards`（近 30 天 forgot/fuzzy ≥2 次的卡 + 概念 + tags）/ `link_cards` / `write_document`（新）/ `write_memory`
   - Agent 分析哪些概念**成对被混淆**（语义相近、都老错）→ 建 confusable 边（已有 card_links type）→ 每对写 memory(layer=mastery, key=confusable:<a>+<b>)
   - 对最强的一对（或几对，上限 1 个专题）**生成对比专题文档**：write_document({title:'对比专题：A vs B', contentMd, topicId?（若两卡同主题）, source:'agent'})
     - documents.source 枚举加 'agent'（drizzle 迁移）
     - 内容：两概念对比讲解（表格或对照段落）+ 2-3 道对比题（compare/judge 型，走 write_cards 或直接写进文档并让 digest 消化？——选择：直接 write_cards 建卡并挂到专题文档，anchor_text 用文档里的对应句子；这样专题卡也进复习队列）
     - 幂等：同一混淆对 30 天内不重复生成专题（查 memory key）
3. 专题文档和正常文档一样出现在文档列表/主题资料流

## 验收
- 造数据：两张易混卡（如偏差/方差）各刷 2 次 forgot → 触发 analyze → psql：confusable 边 + memory 记录 + 一篇 source=agent 的专题文档 → 专题下有对比卡且进了复习队列
- 30 天内再分析不重复生成
