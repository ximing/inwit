## 背景

digest 目前只产出复习卡片，卡片在文档脑图里是一堆无结构的根节点。本任务把消化流程改为：**先建至少两级的脑图大纲（一级=文章标题/章节，二级=标题下 1、2、3 的列表脉络），大纲节点用划线批注形态（quote + anchorBlockIndex，点击跳回原文），再把复习卡片挂到大纲的正确节点下**。同时在文档右键菜单加「AI 消化」人工触发项。

已确认决策（不要再提问、不要翻案）：
- 两级大纲**都用划线批注节点**（不用纯文本章节节点），新批注 kind = `'outline'`。
- 「AI 消化」仅 `status==='failed'` 可点，pending（消化中）/digested（已消化）置灰；不做已消化文档的强制重消化、不做旧文档回填。
- 复用 `planMindEdits` + `applyDocumentMindEdits` 建大纲（原子、quote 逐字校验、canvas 历史记账白拿），不手写 insert。
- outline 批注**硬删**做重消化清理（FK 已验证：`canvas_nodes.annotationId` cascade、`parentId` set null，硬删后挂下面的卡片回落为根）；outline **不进检索索引**。

## 目标 3：digest 新工具 write_outline / place_cards

- 新 `apps/server/src/agent/outline-logic.ts`（纯逻辑）：`outlineEditsFromTree(nodes)` 把两级树扁平化成 `MindEditInput[]`。上限：L1≤12、每节点 L2≤8、总≤60。ref 规则：一级 `s1..sN`、二级 `s1-1..`（REF_RE 要求字母开头）；二级带 `parentRef`；都带 `index` 保序、kind:'outline'。返回 `{ok,edits,refs}` 或 `{ok:false,reason}`。配 `outline-logic.test.ts`：扁平化正确性、各上限报错、空树报错。
- 新 `apps/server/src/agent/outline-tools.ts`：
  - `write_outline`：TypeBox schema（note 1-80 字、blockIndex≥1、quote 1-500 字、children 仅一级节点可有、maxItems 8，nodes 1-12）。execute：`outlineEditsFromTree` → `applyDocumentMindEdits(session.userId, session.documentId, edits)` → 用 refs 把返回的 created 重组成树形 `{ref,nodeId,note,children}` 响应（模型拿 nodeId 做 place_cards 的 parentId）；成功把 nodeId 全部记入 `session.outlineNodeIds`；**重复调用返回 `{ok:false,reason:'大纲已建过，只能建一次'}`**；校验失败返回 `{ok:false,reason}` 不 throw（让模型修正重试）。
  - `place_cards`：schema `{placements: [{cardId, parentId}] 1-40 条}`。cardId 必须在 `session.writtenCardIds` 内（不在直接进 failed）；逐条 `placeCanvasMember(session.userId, session.documentId, cardId, parentId)`，单条失败收集进 failed **不 throw**；成功记 `session.placedCardIds`；返回 `{ok, placed, failed}`。
- `apps/server/src/agent/tools.ts`：`DigestSession` 加可选字段 `outlineNodeIds?: string[]`、`placedCardIds?: string[]`（可选，不破坏 conversation-tools 的 `digestSession()` 工厂）；`digestTools` 在 `readDocumentAnnotationsTool` 后插 `writeOutlineTool`、在 `setDocumentMetaTool` 前插 `placeCardsTool`（→13 个工具）。
