# T2: drizzle schema + 迁移

工作目录 /Users/ximing/project/mygithub/inwit。先读 docs/prd.md（重点 §5 数据模型）。

## 目标
在 apps/server 中实现完整 drizzle schema 并迁移到 inwit_dev。

## 表（§5 为准，字段可自行合理化，用 snake_case，主键 uuid default gen_random_uuid()）
users, llm_configs, threads, captures, cards, card_questions, review_states, review_logs, memories, jobs, agent_executions, llm_usage_logs

要点：
- llm_configs：provider(openai|deepseek|claude|zhipu|dashscope)、api_key_encrypted(text)、model、is_default、base_url 可空
- captures：type(text|ocr|voice|clip|chat)、status(pending|digested|failed)、thread_id 可空外键
- cards：concept/example/confusion_point 三要素 + tags text[] + source(manual|agent|chat)
- review_states：SM-2 字段 ease(real default 2.5)、interval_days、due_at、reps、lapses、last_feedback，唯一约束 (user_id, card_id)
- memories：scope(user|thread) + scope_id 可空、layer(profile|mastery|association|thread_map)、key、content jsonb
- jobs：type(digest|evolve|weekly_report|thread|chat)、status(pending|running|done|failed)、payload jsonb、run_at、finished_at、attempts、last_error
- agent_executions.steps jsonb（每步 {tool, input_summary, output_summary, duration_ms}）
- llm_usage_logs：capability(chat|embed|rerank)、prompt/completion/total_tokens、cost_estimate numeric
- 常用过滤字段建索引（cards.user_id、review_states(user_id,due_at)、jobs(status,run_at) 等）

## 实现
- src/db/schema.ts（单文件即可）
- src/db/migrate.ts（参考 vital apps/server/src/db/migrate.ts 的模式）+ package.json scripts: migrate / migrate:generate
- drizzle-kit generate 生成 SQL，然后对 inwit_dev 执行迁移（连接信息在 apps/server/.env，PG_SSL=false）
- packages/dto 中补齐对应的 zod schema 和 TS 类型（User/Capture/Card/CardQuestion/ReviewState/Thread/Job/AgentExecution/LlmUsageLog），server 引用
