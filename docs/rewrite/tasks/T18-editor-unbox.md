# T18 · 编辑态去"膏药盒"：写作面即页面

先读 `docs/rewrite/CONTEXT.md`。

## 用户反馈

> 中间那个编辑器和大膏药一样，参考其他的编辑器看下，没有这样的

指 `/docs` 编辑态：内容被套在一个带边框/阴影/朱红左边条的"纸卡片"盒子里，悬浮在页面中央，视觉上像一块膏药。主流编辑器（Notion、Typora、iA Writer、Obsidian）**写作面就是页面本身**：没有卡片盒子，文字直接排在页面背景上。

## 任务（`apps/web/src/pages/docs/`、`styles.css`）

### 编辑态改为无盒布局

- **去掉纸卡片容器**：无背景块、无边框、无阴影、无圆角、去掉朱红左边条（"编辑中"的暗示由 chrome 的保存状态 + 编辑/预览分段开关承担，足够）
- 标题 + 正文直接排在 pane 背景上，居中阅读列（max-width ~760px），顶部留白与 chrome 节奏自然（参考 Notion 页面顶部的大留白）
- 标题：无边框宋体大字，与阅读态标题完全同形同位（切换编辑/预览时标题不跳动）
- 正文：与阅读态同一套 prose 排版；placeholder 弱色「开始写，或者从左边扔进来…」
- 聚焦反馈只在文字层（光标、选中色），容器零 chrome
- 编辑/预览切换时布局平稳过渡：预览态的纸卡片保留（阅读有纸张感是对的），但两种模式的**文字列宽、标题位置对齐**，切换不像换了个页面
- BubbleMenu 深色胶囊、划线/批注 Decoration、右侧卡片栏全部保持不变

### 深色模式

- 同步检查：无盒后深色下文字对比度、placeholder 可读性

## 验收

- `pnpm typecheck`、`pnpm -F @inwit/web build` 通过
- 编辑态目检：无任何盒子/边框/阴影包裹内容，观感对齐 Notion 式编辑器
- 编辑⇄预览切换标题与正文位置不跳
- 自动保存、BubbleMenu、划线、卡片栏回归正常
- 浅色/深色都目检
- 不启动/停止 dev server / worker
