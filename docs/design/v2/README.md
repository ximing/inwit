# 设计稿索引

本目录是界面参照，不是整份现行需求。同页若有两份稿，这里不选出哪一份获胜。和实现不一致时，以 `apps/web/src` 里的现行样式为准，不要为了贴近某一份稿去改组件或 CSS。

## 复习

`review.html` 与 `review-redesign.html` 是同一页的两份结构。二者冲突时，实现以现行代码样式为准。本索引不指定胜出稿。

## 仍有效的规格

`topics-hosted-doc.spec.md` 仍说明主题内打开文档的地址和挂载方式，不是过期文档。配套稿是 `topics-hosted-doc.html`。

## 其余

其余 HTML 与 `inwit.css` 只作参照。不要把本目录整夹标成归档。
