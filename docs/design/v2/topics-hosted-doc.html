温度参数是什么？ AI 回答 编辑 · 预览

我先检索一下你是否已有相关卡片，避免重复制卡。你目前的卡片库中没有关于"温度参数"（temperature）的内容，下面是完整解释。

温度参数是 softmax 函数中的一个超参数，写作 T。在计算 softmax 之前，logits 会先除以 T：

pᵢ = exp(zᵢ/T) / Σⱼ exp(zⱼ/T)。当 T = 1 时退化为标准 softmax；T → 0 时分布趋向 one-hot，等价于 argmax；T → ∞ 时趋向均匀分布。▣2

从信息论角度看，T 直接调节输出分布的熵：T 越大熵越高，采样结果越多样但质量方差越大；T 越小越确定，但可能陷入重复。

工程上还有一个配套技巧：计算 exp 前先减去 logits 的最大值，避免数值溢出，数学上与原式等价。
