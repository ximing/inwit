# 概念与关系 M0 原型

入口：[`../concept-relations.html`](../concept-relations.html)。原生 HTML/CSS/JS，无安装步骤。

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/design/prototypes
```

浏览器打开 `http://127.0.0.1:8765/concept-relations.html`。也可直接打开 HTML；推荐 HTTP 预览，以获得稳定的同源 sessionStorage 行为。

- `data.js`：受控示例文章、划线、卡片、概念与关系。默认 8/20/15/12/18；确认模拟生成后最多新增 1 个概念和 1 条关系。
- `app.js`：共享实体、A/B 独立操作状态、图渲染与本地任务流。没有生产 API 调用。
- `style.css`：纸上学习风格及响应式布局。
- `evidence/`：Chrome 设计走查截图和结构化断言结果。

选正文 Trial → 查看关系或全部出现位置。按住画布空白拖动，或使用方向按钮/画布方向键；缩放按钮独立操作两图。章节节点用 Enter/空格展开；分隔线用方向键调整。点击“适应全部”会主动改变当前画布。详情位于本视图内，可随时收起。

共享 card1 可从脑图或 Trial 详情编辑，主要练习目标为 r1，Task/Trial 都只是导航关联。关系详情可编辑源、谓词、目标、解释、例子及出处。本文说明编辑不影响共享定义。

“模拟 Agent 生成”即时构造候选，不模拟真实模型性能；完成仅提示。点击“查看候选”审阅，推断关系默认不选。取消新概念会取消其依赖关系。已确认批次不会重复插入。

当前标签的示例编辑、A/B 各自相机/展开/选择、布局偏好、阅读锚点、列表与详情滚动、搜索过滤、表单、候选和模拟复习回答保存在 `sessionStorage` 的 `inwit:m0:v1:fixture:agent-eval` 键。关闭标签不承诺保留，不与其他标签强制同步。关闭编辑对话框后，再进入同一编辑器可继续草稿；刷新不会自动重开对话框。存储不可用时页面提示只保留内存。

需要回到最初数据时，在新的独立标签打开原型，或关闭原型后清理该键并重新打开。不要清理其他应用的数据。走查工具可模拟 h2 原文修订或删除当前概念，恢复按钮只恢复本原型对象。

完整评估及未验证项见 [M0 评估记录](../../../plans/concept-relations/04-m0-evaluation.md)。这些实现不作为生产数据模型或后端协议。
