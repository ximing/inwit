怎样读懂一次 Agent 测评

评测报告里，我们经常看到 Task、Trial 和 Step。它们指向不同层次，理解这些层次之间的联系，才能正确解读结果。

任务与尝试

这里把 Task 理解为待完成的任务，例如“修复这个仓库中的一个缺陷”。同一个 Task 可以运行多次 Trial，每次 Trial 都是对该任务的一次独立尝试。

重复尝试能帮助我们观察表现是否稳定。一次成功，不代表每一次都会成功。

一次尝试里面发生什么

在本示例中，一个 Trial 由多个 Step 构成。读取文件、执行命令和检查结果，可以是一次尝试中的不同步骤。具体怎样划分 Step，仍需看相应测评框架的定义。

结果如何被衡量

Grader 按规则评判一次尝试的结果。Metric 则规定我们如何衡量表现，例如在指定任务集合和统计口径下计算成功率。
